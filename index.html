About

Write it. Download it. Break it. Fix it.

I build control programs the way they get built on the plant floor: write the logic, download it to the PLC, test it on a physical station, find what breaks, and fix it. Each project here documents the I/O, the logic rung by rung, the bugs I found on hardware, and how I fixed them.

I'm a Computer Science senior focused on industrial controls and automation, looking for opportunities in automation, controls engineering and control system application engineering. Alongside the PLC work, I bring software engineering experience in Python, Java, C++ and SQL from industry-mentored team projects, and I keep every project under Git revision control.
