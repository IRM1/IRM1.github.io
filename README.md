# Controls Portfolio Site

Personal portfolio of PLC and industrial controls projects. Plain HTML and CSS, published with GitHub Pages. No build step.

- `index.html`: home page (about, skills, project cards, contact)
- `projects/`: one page per project
- `css/style.css`: all styles
- `assets/projects/`: screenshots, diagrams and lab station photos

Source files for each project live in the [CONTROLS repository](https://github.com/IRM1/CONTROLS).

## Preview locally

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.
